# 🛒 Ecommerce Website

## 🎯 Objective

The objective of this project is to design and develop a modern, responsive Ecommerce frontend website using HTML, CSS, and JavaScript.  
The website allows users to browse products, view product details, add items to a cart, and subscribe using email validation, providing a smooth and interactive shopping experience.

## 🚀 Features

- 🏬 Modern and responsive UI design
- 📂 Product categories navigation
- 🛍️ Product listing with discounts
- ➕ Add to Cart functionality with live counter update
- 📄 View product details page
- 📧 Email subscription system with validation
  - ✔️ Success message for valid email
  - ❌ Error message for invalid email
- 📱 Fully responsive layout
- 🎯 Smooth user interaction

---

## ⚙️ How to Run the Project

1. Clone or download this repository
2. Open the folder
3. Run `index.html` in browser
   - Double click OR
   - Use Live Server (VS Code recommended)

## 🧠 Functionalities

### 🛒 Add to Cart
- Clicking “Add to Cart” increases cart count dynamically
- Supports multiple product additions

### 📄 Product Details
- Clicking “View Details” opens detailed product page

### 📧 Email Subscription
- Validates email input
- Shows success message for valid email
- Shows error message for invalid email
